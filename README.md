# Fernando Chiavaloni

**Analista de QA Sênior | Automação de testes, APIs e qualidade de dados**

Trabalho com testes de aplicações web, mobile e APIs, análise de regras de negócio, automação e investigação de falhas. A minha experiência recente também inclui processos operacionais e consolidação de dados. Publiquei um case sintético de QA RPA com foco em exceções, rastreabilidade e governança; estou estudando como aplicar as melhores práticas de QA à avaliação de sistemas com IA.



## Portfólio
- [Portfólio de QA e IA](https://github.com/fmchiava/portfolio-qa-automacao): matriz de riscos, laboratório fictício de importação CSV e testes automatizados reproduzíveis.
- [Case de QA RPA e governança](https://github.com/fmchiava/qa-rpa-conciliacao-sinistros): conciliação sintética de sinistros com UI, API, Python, SQLite, tratamento de exceções e evidências auditáveis. A arquitetura A360 é proposta; não há bot exportado.
- [Suíte de testes de API REST](https://github.com/fmchiava/testes-api-playwright): Playwright, TypeScript, contratos Zod, autenticação Bearer, mocks de falha, CI e relatório HTML público.
- [Progresso de aprendizado](https://github.com/fmchiava/portfolio-qa-automacao/blob/master/aprendizado/progresso.md): fontes, experimentos e critérios para registrar resultados.

O laboratório é um exercício com dados sintéticos, desenvolvido com assistência de IA. 
Estudos e ideias planejadas são identificados como tal; não representam entregas de clientes, são projetos inspirados em minha experiência.
